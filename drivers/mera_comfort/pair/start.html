Homey does not talk to the AquaClean directly. It goes through an ESP32 running ESPHome as a Bluetooth proxy, so a few things need to be in place.

  1. Flash an ESP32 with ESPHome. A complete, tested configuration is on GitHub at github.com/torp93/homey-geberit-aquaclean, as esphome/geberit-aquaclean-proxy.yaml.
  2. Before flashing, put your WiFi name and password into ESPHome’s secrets.yaml as wifi_ssid and wifi_password.
  3. Place the ESP32 within a few metres of the toilet, with as little concrete and metal in between as possible.
  4. The next screen asks for the ESP32’s address. Use a fixed IP or a DHCP reservation so it does not move.
  5. Close the Geberit Home app on your phone. The toilet accepts only one Bluetooth connection at a time.

Once that is done, continue and Homey will look for the toilet.
